Batamiga

A Batocera Linux USB image, stripped down to Amiga 500, Amiga 1200 and Amiga CD32 — nothing else.

Batamiga boots straight into EmulationStation with three Amiga systems and no other console, computer or arcade platform present. It ships two emulation engines — PUAE (the default) and Amiberry — plus the open-source AROS Kickstart, so an Amiga 500 or 1200 runs with no copyrighted ROM at all.

What is set up for you

  • Correct Amiga model per system: A500 with Kickstart 1.3, A1200 AGA with 3.1, CD32 with Fast RAM and Akiko.
  • Sensible controls: one-button joystick + mouse for A500/A1200, a 7-button CD32 pad for CD32.
  • WHDLoad launcher enabled; Amiberry runs WHDLoad .lha archives natively.
  • ScreenScraper pre-selected for metadata and artwork (you add your own free account).
  • Custom collections ready to fill: CD32, AGA, WHDLoad, Demos.
  • Automatic Batocera OS updates disabled, so the trimmed system list stays trimmed.

The image contains no games and no Kickstart ROMs. You add your own after the first boot.

Quick start

  1. Flash the image to a USB drive (8 GB or larger). On Windows, run scripts/flash-usb.ps1 -DiskNumber <N> from an administrator PowerShell, or use balenaEtcher.
  2. Boot the target PC from USB (UEFI; disable Secure Boot if needed). Batocera grows the data partition and starts EmulationStation.
  3. Copy games over the network to \\BATOCERA\share\roms\amiga500 (and amiga1200, amigacd32), or use scripts/push-games.ps1.
  4. For real Kickstarts, copy a legally obtained set into \\BATOCERA\share\bios\amiga. See the BIOS section of the README.

A note on Kickstart ROMs

Amiga Kickstart ROMs are copyrighted (rights held by Cloanto). They are not included in this project and never will be. Buy them legally — for example through Amiga Forever — and place them on the data partition yourself. The bundled AROS ROM is open source and covers Amiga 500 and 1200 for getting started; CD32 still needs a genuine CD32 Kickstart.
