# Contributing

Batamiga is a personal project. External contributions are not being
solicited, but notes and bug reports are welcome by e-mail:
sandefjord.development@proton.me

## If you build on it

- All `.md` files in the repository are written in **English**.
- Every user-visible change must be reflected in `README.md` and in
  `CHANGELOG.md` (format: [Keep a Changelog](https://keepachangelog.com/),
  versioning: [SemVer](https://semver.org/)).
- Releases are tagged `vX.Y.Z`. Internal milestone names are never used
  in committed files, commit messages, or release notes — only the
  version.
- Keep the `config/*.patch` files in sync with what is actually applied
  to the local `batocera.linux` clone.
